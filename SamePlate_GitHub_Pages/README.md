# SamePlate Legal

Public privacy and support pages for **SamePlate**, a household dinner-planning and coordination app.

## Site structure

```text
.
├── .nojekyll
├── index.html
├── styles.css
└── privacy/
    └── index.html
```

## GitHub Pages setup

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. Open the published `/privacy/` page in a private/incognito browser window to confirm it is publicly accessible.

Use the public `/privacy/` URL as SamePlate's Privacy Policy URL in App Store Connect and inside the SamePlate app.
